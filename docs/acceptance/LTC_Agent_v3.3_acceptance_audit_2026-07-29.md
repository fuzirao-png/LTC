## 1. 验收结论

**结论：当前不建议通过正式验收，应完成 P0/P1 修复后复验。**

项目已经具备登录、候选线索查询、资源池领取、客户分析、邮件与会议处理等核心骨架，自动化测试的大部分阶段也能通过；但当前仍存在离职后归属语义冲突、销售与管理数据不一致、退出登录 502、关键页面静态数据冒充实时数据、手动记录前端未接真实链路、数据库验收门禁漂移等阻塞问题。

逐项结论为：

| 等级 | 数量 | 含义 |
|---|---:|---|
| A | 0 | 没有项目具备“指标已量化验证且完全达标”的充分证据 |
| B | 8 | 核心能力基本可用，但仍缺性能、并发或完整 E2E 证据 |
| C | 20 | 部分达标，存在明显缺口、规范漂移或关键指标未验证 |
| D | 8 | 未达标或存在验收阻塞缺陷 |
| N/A | 1 | B5 二期零权重项 |

## 3. 验收工作簿自身问题

原工作簿不能作为可信的自动计分器：

1. 总览声明 39 项，详细表实际只有 36 个计分项，另有 1 个零权重二期项 B5。
2. 总览声明平台体验 3 项，详细表只有 F1；声明平台质量 3 项，详细表只有 E3、E6。
3. 平台功能的实际权重合计为 0.98，不是表头声明的 1.00。
4. `v3.3验收总览!D5:D9` 的公式引用了丢失的 Sheet，Excel 会出现 `#REF!`；当前查看器因 `IFERROR` 显示为 0，会掩盖问题。
5. `officecli view issues` 共发现 12 项问题：5 个缺失 Sheet 的公式引用和 7 个文本溢出。
6. 详细表把多项 `v3.4` 和“二期”能力纳入 v3.3 计分，版本边界不一致。

因此本报告给出逐项等级，但不回写原工作簿，也不采用其自动总分。

## 5. 真实缺陷与规范漂移的区分

### 5.1 当前代码中的真实缺陷

1. **退出登录 502**：`apps/api/src/ltc/modules/iam/interfaces/router.py:187-193` 返回注入的 `Response`，运行时状态码为 `None`，Uvicorn 触发 `KeyError: None`。
2. **离职后仍由离职用户持有客户**：`departure_repository.py:43-56` 只写 `handover_pending=true`；`0008_sales_departure_handover.sql:41-80` 明确允许 departed 用户保留 pending active Assignment。
3. **双面板数据不一致**：`DashboardView.vue:16-28,63-75,142-173` 固定日期、KPI、漏斗和排名；与 API 驱动的分配页不一致。
4. **销售状态筛选失效**：`CustomerAllocation.vue:130-136,325` 用后端 `pool_status` 比较中文业务阶段值。
5. **手动记录未接后端**：`CustomerOperation.vue:599-605` 仅写本地提示，没有请求 API。
6. **负向过滤默认通过**：`lead_intelligence/infrastructure/postgres_repository.py:162-163` 可直接写 `none/pass`，没有验收要求的硬过滤证据。
7. **视觉变量和规范不一致**：`style.css:1-30` 的主色、圆角、阴影均偏离表内规范，且没有定义被广泛使用的 `--blue-light/--cyan-accent`。
8. **数据库验收门禁漂移**：`scripts/verify_database.py:16-21` 只应用 `0001`，但当前代码需要后续迁移；容器内运行又会把 `/workspace` 作为宿主挂载路径。
9. **依赖构建不可复现风险**：`apps/api/requirements.txt:9-11` 对 `openai`、`imageio-ffmpeg`、`python-multipart` 只设下限；本次首次构建已出现依赖回溯和网络/TLS失败。

### 5.2 旧标准、Deferred 或缺少外部指标的项目

- A1 的 Exa+Apify、A2 的旧 `raw_lead` 四表口径，与当前 v3.6 事实模型不一致。
- A3 的五场景、A9 的复杂交接、A10/A11 的完整管理能力、B4/B7/B11、E5、E6、F2 在详细表中多被标为 v3.4 或二期，却仍计入 v3.3 总览。
- B6 指定 SendGrid，但当前实现是通用 SMTP；若 SMTP 是经批准的新口径，应先修订验收表。
- 成功率、准确率、p95、打开率、回复率和多语 ASR 指标需要真实环境、样本集和观测周期，单凭代码存在不能判定 A/B。
