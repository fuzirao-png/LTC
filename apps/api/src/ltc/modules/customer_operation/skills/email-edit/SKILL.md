# Email Edit

Edit an existing email in one of two modes:

- `optimize`: improve clarity, structure, professionalism, concision, and call to action.
- `rewrite`: apply a specific user instruction while preserving factual accuracy and business intent.

## Output

Return a unified object with `subject`, `body`, `language`, `changes`, and `model`.
